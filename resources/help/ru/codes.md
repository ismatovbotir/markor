# Коды маркировки

На этой странице показаны все ваши коды маркировки. Здесь можно найти код и проверить его статус. Каждый клиент видит только свои коды. Коды попадают сюда из партий, загруженных через «Импорт CSV».

{{img:codes-1}}

## Колонки списка

1. GTIN.
2. Серийный номер.
3. Товар.
4. Статус: например, **Импортирован** или **Напечатан**.
5. Дата.

## Поиск кода

1. Введите в поле поиска код или GTIN.
2. Список покажет подходящие коды.

## Фильтры

1. В фильтре по товару выберите нужный товар.
2. В фильтре по статусу выберите нужный статус.
3. В списке останутся только коды, подходящие под условия.

## Когда меняется статус

1. После загрузки CSV код получает статус **Импортирован**.
2. Когда для партии создан PDF, код переходит в статус **Напечатан**.

> Чтобы увидеть коды, которые ещё не напечатаны, выберите в фильтре статус **Импортирован**.
