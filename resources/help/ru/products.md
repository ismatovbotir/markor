# Товары

На этой странице показаны товары из ваших кодов. Товары создаются автоматически, добавлять их вручную не нужно.

{{img:products-1}}

## Как появляется товар

1. Вы загружаете CSV-файл.
2. Система берёт GTIN из каждого кода.
3. По GTIN создаётся товар.
4. Название товара берётся из национального классификатора (tasnif.soliq.uz).

## Что видно в списке

1. GTIN.
2. Название товара.
3. Категория.
4. Количество ваших кодов по этому товару.

## Изменение названия

Клиенты не могут менять названия товаров, так как каталог общий.

1. Если название неверное или отсутствует, запишите GTIN.
2. Обратитесь в Markor и сообщите GTIN.

> Если в списке «Импорт CSV» указано «Нет в классификаторе», значит, в национальном классификаторе нет товара с этим GTIN. В этом случае тоже обратитесь в Markor.
