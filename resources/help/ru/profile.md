# Профиль

На этой странице меняются язык интерфейса, личные данные, пароль и данные компании.

{{img:profile-1}}

## Смена языка

1. Откройте меню **Профиль**.
2. Выберите язык: O'zbekcha, Русский или 中文.
3. Весь интерфейс и инструкции переключатся на выбранный язык. Например, сотрудник склада может выбрать удобный для себя язык.

> Язык также можно переключить кнопками UZ / RU / 中文 внизу меню.

## Имя и телефон

1. Измените имя.
2. Измените номер телефона.
3. Сохраните изменения.

## Смена пароля

1. Введите текущий пароль.
2. Введите новый пароль.
3. Повторите новый пароль.
4. Сохраните изменения.

## Данные компании

1. Отредактируйте поля компании: название, адрес, руководитель, телефон, email, код НДС.
2. Сохраните изменения.

Налоговый номер изменить нельзя. Если это нужно, обратитесь в поддержку Markor и сообщите новый налоговый номер.
