# Загрузка CSV

Как загрузить в Markor файл с кодами, полученный от оператора Asl Belgisi. В файле по одному коду маркировки в каждой строке.

## Загрузка

1. Откройте страницу «Импорт CSV».
2. Нажмите **+ Загрузить CSV**.

{{img:upload-1}}

3. Выберите CSV-файл, полученный от оператора Asl Belgisi.
4. Нажмите **Загрузить**.
5. Во время загрузки в окне показывается один из товаров Markor. Подождите.

## Что происходит дальше

1. Файл сохраняется и ставится в очередь.
2. За несколько секунд коды загружаются в базу.
3. После этого файл удаляется с сервера.
4. Следите за статусом партии в списке «Импорт CSV». Когда статус станет **Завершён**, можно создавать этикетки.

> Каждый код можно загрузить только один раз. Ранее загруженные коды пропускаются, причина показывается в списке.

## Если возникла ошибка

1. Проверьте, что это CSV-файл от оператора Asl Belgisi.
2. Убедитесь, что в каждой строке один код.
3. Причины пропуска строк смотрите по красной ссылке в списке.
