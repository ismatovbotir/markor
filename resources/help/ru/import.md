# Импорт CSV

На этой странице показан список загруженных файлов. Каждая загрузка — это одна партия, она называется по имени файла.

{{img:import-1}}

## Колонки списка

1. Партия: имя файла.
2. Товары: название товара, найденное по GTIN, под ним GTIN. Если в национальном классификаторе такого товара нет, указано «Нет в классификаторе».
3. Количество кодов.
4. Сумма к оплате.
5. Статус.
6. Дата.

## Статусы

Статус меняется автоматически:

1. **В очереди**
2. **Загружается в базу**
3. **Проверка товаров**
4. **Завершён**

При проблеме статус будет **Ошибка**. Список обновляется сам, перезагружать страницу не нужно.

## Пропущенные строки

1. Если часть строк не загрузилась, появится красная ссылка «пропущено: N».
2. Нажмите на неё, чтобы увидеть причины.
3. Причины: некорректная строка или код уже есть в системе. Каждый код можно загрузить только один раз.

## Оплата

На панели сверху показаны коды за текущий месяц × цена (9 сумов за каждый загруженный код), скидка и сумма к оплате.

> Сейчас скидка 100%, то есть сервис бесплатный.

## Создание этикеток

1. Дождитесь статуса **Завершён**.
2. Нажмите **Создать PDF**.


## Товар не найден в классификаторе

Иногда GTIN нет в национальном классификаторе (tasnif.soliq.uz). Тогда в строке партии появляется знак ⚠ и надпись «Нет в классификаторе».

1. Нажмите **Укажите название**.
2. Введите хотя бы название товара (на узбекском или русском) и сохраните.
3. Если таких товаров в партии несколько, следующий откроется автоматически.

> PDF можно создать и без названия, но на этикетке его не будет. Если подключён Telegram, бот тоже пришлёт напоминание.
