# 商品

此页面显示您的标识码所对应的商品。商品会自动创建，无需手动添加。

{{img:products-1}}

## 商品如何生成

1. 您上传 CSV 文件。
2. 系统从每个标识码中读取 GTIN。
3. 系统根据 GTIN 创建商品。
4. 商品名称取自国家分类目录（tasnif.soliq.uz）。

## 列表显示内容

1. GTIN。
2. 商品名称。
3. 类别。
4. 您在该商品下的标识码数量。

## 修改名称

商品目录为共享目录，客户无法修改商品名称。

1. 如果名称有误或缺失，请记下 GTIN。
2. 联系 Markor 并提供该 GTIN。

> 如果"导入 CSV"列表中显示"分类目录中未找到"，说明国家分类目录中没有该 GTIN 的商品。这种情况也请联系 Markor。
