# 个人资料

在此页面可以更改界面语言、个人信息、密码和公司信息。

{{img:profile-1}}

## 更改语言

1. 打开 **个人资料** 菜单。
2. 选择语言：O'zbekcha、Русский 或 中文。
3. 整个界面和使用指南都会切换为所选语言。

> 也可以通过菜单底部的 UZ / RU / 中文 切换语言。

## 姓名和电话

1. 修改姓名。
2. 修改电话号码。
3. 保存更改。

## 更改密码

1. 输入当前密码。
2. 输入新密码。
3. 再次输入新密码。
4. 保存更改。

## 公司信息

1. 编辑公司字段：名称、地址、负责人、电话、电子邮箱、增值税代码。
2. 保存更改。

税号无法修改。如需修改，请联系客服。
