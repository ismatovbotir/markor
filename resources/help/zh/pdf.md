# 生成 PDF

为已完成的批次生成标签 PDF 文件，并在标签打印机上打印。

## 生成 PDF

1. 在"导入 CSV"页面找到状态为 **已完成** 的批次。
2. 点击 **生成 PDF**。
3. 从列表中选择标签设计。默认尺寸为 60×40 mm。

{{img:pdf-1}}

4. 在预览中查看标签效果。
5. 点击 **生成并下载**。

{{img:pdf-2}}

6. 页面会显示进度条和预计时间。请稍候。
7. PDF 会自动下载。

## 所需时间

每个标签约 25 毫秒。1,000 个标签约需 25 秒。

## 打印

1. 打开 PDF 文件。每页一排标签，页面尺寸与标签尺寸完全一致。
2. 选择标签打印机。
3. 将缩放比例设为 100%。不要选择"适合页面"。
4. 开始打印。

> DataMatrix 采用 GS1 编码，扫描枪和 Asl Belgisi 系统均可识别。

生成 PDF 后，该批次的标识码状态变为"已打印"。
